# Changelog

Milestone history for ProvenanceLens. Version numbers follow the project's own
convention: the package is at `0.1.0` and no public release has been published, so
this is a phase log rather than a semantic-version history. A release candidate is
suggested in `FINAL_PROJECT_STATUS.md`.

## Phase H — finalisation, reproducibility, documentation, release readiness

* **Reproducibility defects fixed.** `matplotlib` was never declared as a
  dependency while the report writer required it, so a clean `pip install -e .`
  crashed mid-run and left no manifest. Added a `plots` extra, made figure
  generation degrade deliberately with a recorded reason, and removed a
  duplicated `--no-plots` code path. Verified: a minimal environment and a full
  environment produce byte-identical tables and the same report digest.
* **Canonical results.** New `results/phase_g/` — committed, byte-deterministic
  research evidence generated by the same renderers as the scratch output:
  `results.json`, a `RESULTS.md` rendered *from* it, eleven tables, seven figures
  and a manifest with 30 file digests and all 44 pinned revisions. New
  `study publish` and `study verify-canonical` commands.
* **Offline demo.** `python -m provenancelens.demo` walks through six curated
  cases (KEEP, ADD, REPLACE, ABSTAIN; adapter and merge; REAL and CONTROLLED
  clearly labelled) using only frozen evidence.
* **Console interface.** `provenancelens audit | demo | benchmark | study`, reusing
  the existing audit renderer rather than duplicating it.
* **Documentation set.** `docs/ARCHITECTURE.md`, `METHODOLOGY.md`, `RESULTS`-linked
  `LIMITATIONS.md`, `THREATS_TO_VALIDITY.md`, `CLAIMS.md`, `QUICKSTART.md`,
  `REPRODUCIBILITY.md`, `PAPER_NOTES.md`; README restructured as a reviewer entry
  point; `FINAL_PROJECT_STATUS.md` and this changelog added.
* **Report defects corrected** (no metric changed): an evidence-usage definition
  that asserted a property the data contradicted; unrounded interval bounds in the
  stratum table; an ablation figure with clipped value labels; a risk–coverage
  figure whose filled band implied unmeasured coverage. Every metric table is
  byte-identical to the Phase G baseline.
* **Integrity tests** for documentation/results consistency, demo cases, canonical
  manifest, notebook hash, production immutability, CLI help and offline import.

## Phase G — experimental study

* **Real track expanded 3 → 44 adjudicated repositories** under a frozen
  stratified acquisition plan (six strata, fixed quotas, recorded exclusions, all
  selected cases kept). 26 CONTROLLED + 44 REAL = 70 cases.
* **New metadata state** `INCOMPLETE` (parent declared, relation absent) with
  validation rules; `ADD` recognised as the safe repair for it.
* **Nine evidence-transform ablations** run through the unmodified engine, each
  with a pre-registered hypothesis and a reported verdict.
* **Analyses:** headline metrics with Wilson 95% intervals, risk–coverage sweep,
  single-assignment failure taxonomy, evidence presence vs decisiveness, per-stratum
  results from the acquisition plan's own strata.
* **Deterministic artifacts:** 31 outputs, byte-identical across runs, with a
  manifest of input/output digests and an environment that does not alter results.
* **Optional local-LLM comparator** (`llama3.2:3b`): 20 claims, 0 accepted,
  0 false repairs; grounded rejections documented.

## Phase F — LineageRepairBench

* Benchmark schema, self-validation, CONTROLLED and REAL tracks.
* Metric semantics: strict vs coverage-conditioned, zero denominators, all-abstain
  and no-abstain systems, Phase F False Repair Rate definition (denominator =
  attempted repairs) with unverifiable attempts reported separately.
* Six baselines, selective threshold sweeps, calibration guardrails that refuse to
  treat `support_score` as a probability, extraction evaluation, CLI.

## Phase E — optional local LLM prose extraction

* LangChain chain (`PromptTemplate | ChatModel | text parser | structured parser`)
  with a versioned, digested prompt.
* Grounding validation: quoted span must exist, parent must occur in it, relation
  must be canonical, a lineage statement must be present.
* Typed failure codes for malformed, refused, timed-out and unavailable paths;
  prompt injection handled as untrusted data; graceful fallback to deterministic
  extraction. Never downloads a model; no paid API.

## Phase D — evidence reasoning and repair decisions

* Conservative identifier resolution (never queries a hub).
* Candidate aggregation, evidence independence with per-file caps, reliability
  weighting, structured conflict detection.
* KEEP / ADD / REPLACE / ABSTAIN with an `AuditDecision` and a `SuggestedPatch`
  that is only ever a recommendation.

## Phase C — evidence collection

* Safety-first Hugging Face collector: provenance-relevant text only, weights and
  binaries excluded before download, hard byte cap, structured per-file statuses,
  two injectable seams for offline testing.
* Frozen snapshots keyed by `repository + commit sha`, read-only, SHA-256 per
  file, with hash/UTF-8/path-safety verification on load.

## Phase B — structured package

* Conversion of the prototype into a Python package with typed schemas
  (evidence, lineage, collection, snapshot, audit), deterministic parsers, and a
  regression suite.

## Phase A — audit

* Audit of the original Phase-2 notebook, preserved byte-identical as
  `ProvenanceLens_Phase2 (1).ipynb` and superseded by Phases B–H.
