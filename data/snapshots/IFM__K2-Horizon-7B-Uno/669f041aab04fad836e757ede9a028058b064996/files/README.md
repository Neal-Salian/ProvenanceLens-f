<h1 align="center"><strong>K2-Horizon-7B-Uno</strong></h1>

**Paper:** [Unlocking Lossless Speedups in LLMs via Discrete Diffusion](https://huggingface.co/papers/2609.04010)  
**Project Page:** [https://s-sahoo.github.io/uno/](https://s-sahoo.github.io/uno/)  
**Code:** [https://github.com/ifm-ai/uno](https://github.com/ifm-ai/uno)

We present `K2-Horizon-7B-Uno`, a diffusion-augmented LLM with two pathways in a unified architecture:
- The AR pathway uses the AR weights of the [K2-Horizon-7B](https://huggingface.co/IFM/K2-Horizon-7B) model.
- The diffusion pathway augments these weights with LoRA-based diffusion adapters.

![results_overview](./results_overview.png)


This repository contains the adapter only. The base-model weights are hosted separately in [**IFM/K2-Horizon-7B**](https://huggingface.co/IFM/K2-Horizon-7B).

## Code

Selected evaluation scripts are available in [**scripts/k2_horizon**](https://github.com/ifm-ai/uno/tree/main/scripts/k2_horizon). The full evaluation suite will be released soon.


## Evaluation results

best score in each row. `--` and `N/A` denote unavailable results.
